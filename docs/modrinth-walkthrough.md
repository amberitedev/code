# Modrinth UX walkthrough

This branch exists to host screenshots and recordings in its pull request, at Ilai's request. It is not an Amberite implementation proposal.

The walkthrough uses the original Modrinth client at upstream commit `eacc38fb51ad7ef5c66714afebd66e24b4ec9301` with local substitutes for the private Hosting and Shared Instances services. Accounts, servers, files, and events shown by those substitutes are fixtures, not a paid Modrinth Hosting account.

Capture the local instance screens separately from the Hosting panel. A saved multiplayer address, server-managed shared content, and permission to manage a hosted server are distinct states. A fixture can demonstrate how the client renders a state, but cannot prove how Modrinth's private backend creates it.

Media will be attached to the pull request rather than committed as binary files. No real account credentials, personal instance files, or unrelated desktop windows should appear in the captures.
